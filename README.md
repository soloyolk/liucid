# LIUCID website — GitHub Pages

This is a static website package for GitHub Pages. No build step or framework is required.

## Publish
1. Create or open the GitHub repository you want to use for `liucid.com`.
2. Upload the contents of this folder to the repository root. Keep `index.html` at the root and keep the `assets/` folder beside it.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. If you use a custom domain, set `liucid.com` in the Pages custom-domain field and configure the DNS records GitHub provides.
